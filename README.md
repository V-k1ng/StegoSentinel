# StegoSentinel: Нейросетевой комплекс стеганоанализа пространственной области

**StegoSentinel** — это специализированный программный комплекс, разработанный для нужд цифровой криминалистики (форензики) и аудита информационной безопасности. Система предназначена для автоматизированного обнаружения, локализации и извлечения скрытых данных, внедренных в растровые графические контейнеры методом наименьшего значащего бита (LSB).

Основная техническая ценность проекта — уверенное детектирование **низкоплотных стеганограмм (плотность заполнения от 15%)**, которые полностью маскируются под естественные шумы матриц и пропускаются классическими статистическими тестами (такими как $\chi^2$ или RS-анализ).

---

## 🛠 Ключевые технологические решения

### 1. Слой SRM-препроцессинга (Spatial Rich Models)
Вместо анализа семантического контента изображения (объектов, людей, сцен), нейросеть сфокусирована исключительно на микроструктурном шуме. На входной сверточный слой подаются карты остаточного шума, полученные путем пропускания тензора через фиксированные ядра пространственного дифференцирования ($k_1, k_2, k_3$). Это подавляет изображение и усиливает малоамплитудные аномалии младших битов пикселей.

### 2. Алгоритм «Скользящего окна» (Sliding Window Scan)
Классическое масштабирование (`Resize`) уничтожает LSB-внедрения из-за интерполяции пикселей. Аналитический модуль разбивает входное изображение высокого разрешения на непересекающиеся блоки размером $256 \times 256$ пикселей и сканирует их поочередно, формируя тепловую карту детекции и локализуя зоны внедрения улик.

### 3. Потоковый Byte-oriented Экстрактор
Извлечение данных происходит на уровне сырого потока байт (`bytearray`) с поиском стоп-маркера `#####`. Алгоритм устойчив к мультибайтовым кодировкам (включая Кириллицу UTF-8) и аппаратно защищен от крашей (Memory Crash Protection) при анализе чистых файлов за счет лимитирования зоны просеивания.

### 4. Инжектор со случайным зашумлением (Noise Padding)
Модуль скрытия данных позволяет задавать точную плотность зашумления контейнера. Если секретный текст занимает меньше указанного объема, система генерирует криптографически стойкую псевдослучайную последовательность бит для заполнения остатка, имитируя распределенный стего-канал.


### 🚀 Быстрый запуск и развертывание
Требования к окружению
Операционная система: Windows 10/11

Интерпретатор: Python 3.10 - 3.11

Рекомендуется дискретный графический ускоритель с поддержкой CUDA (для ускорения работы нейросети).
